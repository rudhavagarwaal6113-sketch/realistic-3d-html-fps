# IRONLINE — Realistic 3D HTML FPS

A browser-based first-person shooter prototype using Three.js/WebGL.

## Current build
- True 3D first-person camera and mouse look
- Procedural training-range environment
- Dynamic shadows, fog, tone mapping and lighting
- Weapon rendered in first person
- Shooting with raycast hit detection
- Head/body damage
- Muzzle flash and hit particles
- Recoil and weapon sway
- ADS (right mouse)
- Sprint and crouch
- Jump + gravity
- Reload system and HUD
- Moving targets

## Run
Open `index.html` through a local web server. Because ES modules are used, do not rely on `file://` in browsers that block module loading.

## Controls
WASD move · Shift sprint · Ctrl crouch · Space jump · Left mouse fire · Right mouse ADS · R reload · Esc pause.

## Road to AAA-style browser FPS
A Call of Duty-level experience is possible only as a much larger project. The next major upgrades are GLTF/FBX weapon and character assets, physically based textures, animation systems, spatial audio, navmesh AI, multiplayer networking, server authority, ballistic simulation, dedicated maps, post-processing, and aggressive performance optimization.
